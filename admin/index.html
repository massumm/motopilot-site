    How this reaches riders

    Publishing writes the message to the database. The app reads it on launch and shows it as a banner — so it arrives whenever the rider next opens MotoPilot, not as a system notification.

    A true push notification has to be sent by a server holding a credential. Putting that credential in this page would let anyone who views the source notify every user, so it is not here. Sending one needs either the Firebase Console, or a Cloud Function on the Blaze plan that watches this same message.

    What this counts

    One row per install, written when the app launches: a timestamp, a version number and a language. No location, no bike, no fuel history — nothing that could say who a rider is. An install that has never had a connection is not in here at all, so treat these as a floor rather than a total.

    Minimum version

    Installs below this versionCode are blocked and shown the update screen. Set it to 0 to block nobody. Raising it stops a broken release without shipping another one — and a wrong value here locks every rider out, so it is deliberately a number you type.
